# House Price Prediction using Linear Regression (KZ-ML-01)

A machine learning web application that estimates house prices from measurable
features (area, bedrooms, bathrooms, stories, parking, amenities and furnishing
status), built around a Linear Regression model compared against a Decision
Tree Regressor, served through a Flask web app with prediction history.

## Folder structure

```
house_price_prediction/
├── data/Housing.csv                       # 545-row training dataset
├── notebook/house_price_training.ipynb    # EDA + training + evaluation (executed, with outputs)
├── model/model.pkl                        # best trained model (joblib)
├── model/columns.pkl                      # ordered feature-column list used at inference
├── model/metrics.json                     # R2 / MAE / RMSE for both models
├── decision_tree.py                       # from-scratch CART regressor (see note below)
├── app.py                                 # Flask application
├── templates/                             # index, result, history, insights, base
├── static/css/style.css                   # custom UI theme
├── static/images/                         # EDA charts generated by the notebook
├── scripts/generate_dataset.py            # regenerates data/Housing.csv
├── scripts/build_notebook.py              # (re)generates the .ipynb from source
├── predictions.db                         # SQLite prediction history (created at runtime)
└── requirements.txt
```

## Setup

```bash
pip install -r requirements.txt
```

## Run the web app

```bash
python app.py
```

Then open http://127.0.0.1:5000 in a browser. Fill in the form and submit to
get an instant price estimate; every prediction is logged to `predictions.db`
and shown on the **History** page. The **Model Insights** page shows the
R²/MAE/RMSE comparison and the EDA charts.

## Retrain the model

Open `notebook/house_price_training.ipynb` in Jupyter (`jupyter notebook`) and
run all cells. It will reproduce `data/Housing.csv` preprocessing, regenerate
the EDA charts in `static/images/`, retrain both models, and overwrite
`model/model.pkl`, `model/columns.pkl` and `model/metrics.json` with whichever
model has the better test R².

To regenerate the synthetic dataset itself (545 rows, same schema as the
Kaggle "Housing Prices Dataset" by Yasser H.):

```bash
python scripts/generate_dataset.py
```

## Note on the Decision Tree Regressor

This project trains and compares **two** models as required: Linear
Regression and a Decision Tree Regressor. On this machine, scikit-learn's
compiled tree extension (`sklearn.tree`, via `sklearn.neighbors._quad_tree`)
is blocked by a Windows Application Control / WDAC policy, so
`decision_tree.py` provides a small from-scratch CART regression tree with
the same `fit`/`predict` API, using the same SSE/variance-reduction splitting
criterion scikit-learn uses by default. The notebook imports it as:

```python
from decision_tree import SimpleDecisionTreeRegressor as DecisionTreeRegressor
```

If your machine does not have this restriction, you can swap that line for
`from sklearn.tree import DecisionTreeRegressor` and everything else works
unchanged. In this project's run, Linear Regression wins on test R² (≈0.65)
and is the model actually served by the Flask app — which also matches the
expected real-world result, since the data's price-generating relationship is
closer to linear than to a shallow tree's step function.
